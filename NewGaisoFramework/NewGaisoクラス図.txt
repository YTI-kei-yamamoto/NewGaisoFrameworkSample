    ' ==========================================
    ' 継承・実装・集約・依存関係
    ' ==========================================
    ExteriorMaterialComponent <|-- PanelComponent
    ExteriorMaterialComponent <|-- MatComponent
    ExteriorMaterialComponent <|-- BoardComponent
    ExteriorMaterialComponent <|-- FittingsComponent

    IMaterialCatalogRepository <|.. SqliteMaterialCatalogRepository : 実装

    KojiData "1" *-- "1" GaisoModel : 集約所有
    KojiData "1" *-- "0..*" GridLineAxis : 通り芯定義
    GridLineAxis --> GridDirection : 方向

    GaisoModel "1" *-- "1..*" GaisoPlane : 外装平面群
    GaisoPlane "1" *-- "1..*" GaisoSurface : 外装面群
    GaisoSurface "1" *-- "1..*" ExteriorSurfaceElement : 面要素群
    GaisoSurface "1" *-- "4" Vector3D : 原点・軸・法線
    GaisoSurface "1" *-- "0..*" OpeningRect : 開口情報

    ExteriorSurfaceElement "1" *-- "0..*" ExteriorMaterialComponent : 構成要素(順序管理)

    MaterialCatalogItem --> MaterialCategory : 区分
    MaterialCatalogItem ..> ExteriorMaterialComponent : CreateComponent()生成

    ExteriorMaterialComponent ..> LocalizedDisplayNameAttribute : プロパティ表示名
    ExteriorMaterialComponent ..> LocalizedCategoryAttribute : カテゴリ表示名
    LocalizedDisplayNameAttribute ..> LocalizationService : 翻訳取得
    LocalizedCategoryAttribute ..> LocalizationService : 翻訳取得

    Program ..> LocalizationService : Translations.db初期化
    Program ..> OdaDwgKojiDataReader : DWG読込
    Program ..> KojiData : 工事データ生成
    Program ..> MainForm : 起動

    MainForm --> KojiData : モデル操作
    MainForm --> GaisoSurface : 選択中面
    MainForm --> IMaterialCatalogRepository : カタログDB参照
    MainForm --> UserLayoutSettings : 画面比率・言語設定保存
    MainForm *-- ExteriorViewportControl : ElementHost内包
    MainForm ..> LocalizationService : 言語切替・UI更新
    MainForm ..> MaterialCatalogDialog : モーダル表示
    MainForm ..> OdaDwgKojiDataReader : DWGインポート

    MaterialCatalogDialog --> IMaterialCatalogRepository : マスタ検索
    MaterialCatalogDialog --> MaterialCatalogItem : 選択結果保持
    MaterialCatalogDialog ..> LocalizationService : ダイアログ翻訳

    ExteriorViewportControl *-- "0..*" AnnotationAnchor : 2D投影ラベル
    ExteriorViewportControl --> KojiData : 3D/2Dメッシュ構築
    ExteriorViewportControl ..> MaterialTextureService : 3Dマテリアル生成
    ExteriorViewportControl ..> LocalizationService : HUDテキスト翻訳
    ExteriorViewportControl ..> MainForm : SurfaceClicked通知
@enduml
